Deliverables: `scripts/r10/run-matrix.mjs`, `artifacts/r10/matrix/`, this file.

## What is implemented
1. One frozen `SCENARIO` (`matrix/scenario.json`, SHA `02a1a73c…`) drives every game: world, candidates, council, rescue, night skip, D2 interference, clock. Memory budget 640 everywhere, asserted equal.
2. 2 heads × raw/conditional × 2 fresh seeds = 8 live games; CPU reference arm on the same seeds and both memory fills = 4 games.
3. A game saves at the first round at/after D2 08:00 that has real working intents, exits, and a NEW process loads session+sidecars, rebuilds the P loop and `createCommitmentBridge` (guards/projectors, projection replay), then runs to D4 18:00. `resume-load.json` records both pids and the loaded intents.
4. Live gates: no commitment input 10, head missing 12, manifest 13, SHA 15, renderer 14, scorer/binding 16, unsettled settlement 17, replay 18. Failures are recorded; no rule/replay substitute.
5. Metrics: verified fulfilment, authorised exit, deadline timeout, post-cancel effects, unauthorised changes, duplicate receipts, no-progress rounds; plus survivors, coverage, furnace hours, crises, work hours, forwards, GPU wall. Busy skips are separate; rejected/unresolved settlements counted.
6. Same-action replay is a separate control (`replay.json`, `countsAsModelResult=false`).

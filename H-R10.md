# H — R10 eight-game matrix and the D2 save/exit/resume (codex/r10-H)

Base `054cab0` (tree `acac9d3`, `main@55c92ae`), independent worktree `r10-wt/H`, not merged.
Deliverables: `scripts/r10/run-matrix.mjs`, `artifacts/r10/matrix/`, this file.

## What is implemented
1. One frozen `SCENARIO` (`matrix/scenario.json`, SHA `02a1a73c…`) drives all games: world, candidate layer, council, rescue, night skip, D2 interference, clock. Memory token budget is 640 everywhere and is asserted equal per game.
2. 2 heads × raw/conditional × 2 fresh seeds (`r10h-1`, `r10h-2`) = 8 live games; the CPU reference arm runs the SAME two seeds and both memory fills = 4 games.
3. Each game runs D1→D2 and saves at the first round at/after D2 08:00 that has real working intents, then the process exits. A NEW process loads session+sidecars, rebuilds the P loop and `createCommitmentBridge` (guards/projectors re-registered, pending projections replayed), then runs to D4 18:00. `resume-load.json` records both pids, the loaded intents and the projection replays.
4. Live arms call the real 27B service. Gates (a failure is recorded, never replaced by rules/replay): missing head 12, bad manifest 13, SHA 15, renderer 14, no commitment input 10 (refuses to start), scorer failure 16, unsettled settlement 17, replay 18.
5. Metrics: verified fulfilment, authorised exit, deadline timeout, post-cancel physical effects, unauthorised term changes, duplicate receipts on one instance, no-progress rounds; auxiliary: survivors, coverage hours, furnace-lit hours, crises, work hours, real forwards, GPU wall seconds. Busy skips are separate and not model failures; rejected/unresolved settlements are counted.
6. Same-action replay is a separate control (`replay.json`, `countsAsModelResult=false`) and is never counted as a game result.

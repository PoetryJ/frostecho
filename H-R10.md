# H — R10 eight-game matrix and the D2 save/exit/resume (codex/r10-H)

Base `054cab0`, independent worktree `r10-wt/H`. Head source: `codex/r10-c` (`150f579`), files under `r10-wt/c/artifacts/r10/c/train-primary/`.
Deliverables: `scripts/r10/run-matrix.mjs`, `artifacts/r10/matrix/`, this file.

## What is implemented
1. One frozen `SCENARIO` (`matrix/scenario.json`, SHA `02a1a73c…`) drives every game: world, candidates, council, rescue, night skip, D2 interference, clock. Memory budget is 640 everywhere and asserted equal.
2. 2 heads × raw/conditional × 2 fresh seeds = 8 live games; CPU reference arm on the same seeds and both memory fills = 4 games.
3. Each game runs to D2 and saves at the first round at/after D2 08:00 with real working intents, then exits; a NEW process loads session+sidecars, rebuilds the P loop and `createCommitmentBridge` (guards/projectors, projection replay) and runs to D4 18:00. `resume-load.json` records both pids and the loaded intents.
4. Live gates: no commitment input 10 (refuse), head missing 12, bad manifest 13, SHA 15, renderer 14, scorer/binding failure 16, unsettled settlement 17, replay 18. A failure is recorded, never replaced by rules/replay.
5. Metrics: verified fulfilment, authorised exit, deadline timeout, post-cancel effects, unauthorised changes, duplicate receipts, no-progress rounds; auxiliary survivors, coverage, furnace hours, crises, work hours, forwards, GPU wall. Busy skips are separate; rejected/unresolved settlements are counted.
6. Same-action replay is a separate control (`replay.json`, `countsAsModelResult=false`).

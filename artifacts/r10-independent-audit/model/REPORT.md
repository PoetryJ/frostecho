# R10 C 独立核查：训练确已发生，当前数据不能支撑长程增益结论

核查冻结源码 `288a28859a4eb872345771d25618769e127e434b`，本审查没有模型/GPU/API调用或生产代码修改。脚本 `audit_r10_training.py` 只用NumPy读取真实缓存、重算LN/评分、逐项核对分支事实和分区；结果在 `independent-training-audit.json`。

CPU复跑：`python audit_r10_training.py --repo <冻结源码目录> --out <新JSON>`；`python check_manifest_contract.py --repo <源码> --out <新JSON>`；`python summarize_cost.py --repo <源码> --out <新JSON>`。仅NumPy与标准库；不需Torch、权重主干或GPU。未入库的825MiB快照/逐分支状态未在本子任务重跑，所以2039条的独立范围是记录绑定及终局谓词复算，非逐分支重新执行的真实性证明。

## 有效结果

- 312案/12episode/2039候选分支可从原始记录重算：primary/discharge 为223全接受、70全不接受、19区分；base为281全接受、0全不接受、31区分。独立谓词复算和导出标签一致，没有手工“非wait都对”的标签规则。
- 采集真由参考策略在共享runStep运行中到达，8个NPC轮换；8案确有medical候选；12次确为工作开始后中途取消并结算。它修正了R9构造缺陷。但行为策略是reference，并非JEV；只采D1/D2，未启完整原图、未挂送饭goalBridge。它证明参考策略访问数据管线，未证明JEV长程访问分布上的学习。
- 实际只将隔条采样的156案编码（91train/39dev/26test，7/3/2个episode）；156均为不同可见输入，无跨episode/可见输入的分区泄漏。两个test episode恰好都scarce场景，结论范围应受此限制。
- GPU缓存 `4dae52c7…` 的1020×5120候选特征、records/identity/SHA匹配。独立重算两配方的8个新头及初始头，记录中保留6位的dev/test指标全部吻合。**8头权重均已改变，曲线均40epoch**；没有功效不等于没有训练。
- base选warm17(epoch1)，其test26/26，初始头也是26/26；discharge选random17(epoch3)，其非空标签test18/19（区分2/3），初始头16/19（区分0/3）。这是极小留出子集的结果，不能当作长程履约提升。另两warm头test19/19只能作为探索性记录，不能看完test后换选头。

## 本质限制与正确归因

1. **有效学习信号少。** base优化器接91train，其中83全接受、仅8区分；discharge接74非空train，其中68全接受、仅6区分，17空集直接跳过。全接受集合的set-NLL恒为0，标签梯度为0；AdamW仍可能造成衰减，所以不能说权重不变或根本没训练。空集样本也没有训练拒绝/求助或恢复策略。
2. **随机分母要一致。** primary全312的均匀随机命中率74.72%，排除70空集后242题为96.33%。base test26随机98.56%；discharge test26随机63.56%，排除7空集后的19题随机86.97%，其中3个区分题随机17.5%。不能拿全体随机74.72%与丢弃空集后的模型94.74%直接相比。
3. **dev精度饱和，不是无梯度或早停。** base四头记录dev NLL均四舍五入为0，代码按已舍入值比较并用epoch/warm/seed确定选择；独立原始NLL分别约1.03e-7/2.00e-8/4.71e-8/1.60e-8。选择过程符合已声明规则，但实际上由tie-break决定，改用未舍入值只修精度，不增加任务辨别力。
4. **终局时点混杂。** `label-branches.mjs` 先等首动作完成，再统一继续120分钟；312/312案各候选的绝对terminal.simTime不同，相差最多60分钟，实际观察时长为120/130/135/140/180分钟。这是“动作后继续固定时长”的SMDP延续值，不能直接解释为同一承诺deadline前哪动作更好。长动作额外得到推进世界和完成义务的时间。需从共同t0设固定deadline=t0+H；动作尚未完成就保持pending，所有分支到同一时刻比较。若需不同H，预登记各H并对所有分支统一应用。
5. **宽/空标签反映环境与控制器。** 70空集里45案所有首动作均已成功应用，但固定后续控制器仍无法在终点清偿义务；这不是所有首动作都违法。参考控制器还能补救首动作，可能冲淡其影响。focal-idle则改变整个后续策略，也不能假装只是更严标签。保留多种可行选择，不可强造唯一正确答案。

## 服务契约与成本

实际生产函数的metadata-only复跑见 `manifest-contract.json`：交付manifest的schema已经是 `frostecho.action-weak-experiment/1`；真正被 `serve_joint.load_training_manifest` 拒绝的是诚实的 `labelSource=same-snapshot-branch-rollout`，服务只接受`reference-imitation`。artifact内`serveCompatibility.matchesSchema=false`是描述错误。R10矩阵harness已记录省略`--training-manifest`的原因，并逐回复绑定headSHA、featureIdentityHash和rendererId；不能等同R9完全漏绑定。但web/CLI普通服务入口不能继承这个harness保障。正确修复是共享一个版本化manifest validator，允许明示的分支标签源并保留experimental/admission关闭、头/renderer/encoding资格校验；随后实际传manifest。仅补命令参数会在加载前失败，改标签源冒充模仿也不成立。

成本见 `cost-independent.json`：交付GPU1混合编码158次（156案+2资格前向），逐次GPU峰值最高19606.89MiB；forward计时合1521.12秒，首started→末completed1657.81秒，metadata invocation1672.40秒。约0.465单卡时是流水线时长估计；完整进程显存驻留、3次身份加载探针、空闲间隔和全部尝试的总卡时未获完整监控，保留unknown。两配方头训练为CPU约11.77+9.96秒。作废CPU编码5803秒和早期CPU探针1157秒均不能算实际GPU卡时。

## 下一轮可执行功效门与对照

**CPU先做真实信息增量，GPU跟随。** 在完整地图、同一承诺桥接/授权/时间入口上采参考与当前JEV访问状态，事件干预涵盖已听见/未听见取消、改源未同意、失败条件解除、两承诺争资源；每个源episode及其所有分支/排列只属一个分区。保留取消后所有新动作合法的控制题，不为了提高难度把它们改成非法。

对同快照、相同候选、相同绝对deadline逐一分支；所有臂使用同一明确的继续策略，记录真实履约、待履行量、逾期、授权/终态违规、资源净变化和人时。控制器未能履约与首动作违法分开。依据真实结果保留可接受/Pareto集合和并列；仍全相同时标记无辨别力，空集留作恢复/求助问题，不硬塞进分类训练。先做不少于48个候选状态的CPU开发池，覆盖至少12个完整source episode；用与策略无关的资源/义务条件分层抽样，报告自然分布与挑战集两份结果。**启动新编码前要求**至少4类故事各有可复算的不同后果例、开发池有至少24个真正区分状态且不靠候选删到唯一，另留未看结果的episode作确认；数量是建议的工程信息门，不是统计显著性证明。

**公平基线拆开两维。** 若要回答“新训练是否改善”，固定renderer `/2`、编码器身份、候选、episode分区和预算，旧配方也在相同新状态池上重训（warm/random×17/43），以相同dev规则选头；初始旧权重只作为迁移基线。若还要回答“来源表示是否改善”，另做旧/新renderer × 旧/新训练配方的2×2，四格各自真实重编码/重训，使用同一语义案件与标签/留出episode；`/1`旧头直接在`/2`输入上比较不等于该2×2。所有选择用未舍入dev指标，别按test选种子。

**两个盲审agent负责标签可辩护性。** 隐去来源策略/头分数/模型选择/另一审阅者和当前标签，仅给当事人可见历史、候选、授权约束；先各自判断可接受集合及不确定原因，再另页核验匿名分支事实与deadline计分。审阅者若认为多个行动都合理应全部保留。分歧按原因隔离，先在dev修规则；不要用一致率替代履约结果、不要在test反复裁到一致。保留独立会话ID、模型/配置、输入SHA与原始返回以证明独立性。

最终评估固定相同seed/资源/记忆预算，跑旧配方×raw、新配方×raw、旧配方×conditional、新配方×conditional，另有reference；至少2个未用于选模的完整四日episode，各臂D2保存退出、新进程继续。按承诺实例统计履约/逾期/取消后执行/未授权改约，按源episode报告配对差异，连同资源与实际前向/成本。没有长程差异时写平局，并定位输入不可辨、候选不可行、标签无信息或模型未利用信息，再决定停止哪一方案；不以26条满分宣称完成。

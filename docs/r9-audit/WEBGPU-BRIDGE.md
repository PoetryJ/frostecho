# WebGPU融入边界（给O/E/H）

已核实来源：FrostEcho-WebGPU main @ f77bf5453465d0ade53070c4589498867209aabe，继承地图来源为FrostEcho @586034f；偏好来自负责人“拆解深渊花园实现原理”会话：第三版白障风暴、沉浸风雪与音效、暖窗方向感。现有原型为自由飞行的静态村庄，不能当现成游戏或NPC寻路。

## 一条权威链，两个视图

FrostEcho的CLI/session/runtime仍决定时间、资源、地图/门、行动、回执和存档。WebGPU只消费稳定快照与已提交事件；相机、LOD、Bloom、音效、画面插值不能修改仿真。菜单命令通过现有游戏HTTP/CLI回送并等待真实回执，不在WebGPU本地加资源、移动NPC或判履约。

O/H导出VisualSnapshot/1：sessionId、单调worldVersion、simTime、profile/map数据身份、NPC id/mapId/grid cell/正在执行actionId与阶段、公共资源、炉/机器状态、最近已提交事件序号。义务面板可显示玩家获准查看的状态；NPC私有记忆不进入图形快照后再流回模型。乱序快照拒绝，重连/恢复用全量快照与明确sessionId刷新，不能插值穿越不同存档。

8NPC按稳定id映射可辨识的角色，位置来自权威网格。当前约定一格2米，X=(gridX−25)×2、Z=(gridY−20)×2；高度由展示地形采样。建筑门和室内位置按各自mapId映射，不能将七个室内坐标直接当村庄坐标。优先让村庄、仓库、厨房的实际穿门/取粮/送饭可见；其余室内随原作完成度联动，未实现必须明示，不能让角色假穿墙。

移动只在真实提交的路径上插值；断线显示最后确认状态并标连接中，不继续“演戏”。未来计划只能显示为意图。炉火强弱/生产/烟/交付反馈绑定权威状态与receiptId；装饰脚印和解析飘雪不能标成NPC已走过路线或真实天气。已有美术预设保留为观赏模式；游戏天气模式另绑定仿真，避免美术切换改变规则。

默认保留用户选定的白障风暴。关键角色/门/任务目标提供可读标记与总览切换，不能因浓雾让游戏无法操作。音效由用户操作开启，背景运行/暂停可静音；不把自由相机穿墙误称玩家碰撞已完成。

## 两仓库与交付

业务权威在frostecho，绘制在FrostEcho-WebGPU；不做双向跨仓库源码导入。优先由现有游戏服务同源托管固定版本图形资源与状态适配器，或构建固定SHA展示包，交付锁明两个commit和协议版本。不要简单放宽CORS来绕开接线；同源命令沿用现有校验。保留旧2D视图作为不支持WebGPU时的同状态入口，设备丢失不影响后台仿真/存档。

渲染GPU使用玩家本地显卡，27B推理仍在服务器服务；不得把模型权重或API密钥发给浏览器。E不占用A10另开模型。无浏览器时CPU检查可以继续，但视觉验收标未完成，不能用静态截图或预录轨迹冒充在线。

验收：实际点击派工→模型选择→真实移动/工作→回执→资源/任务更新；运行中取消；D2退出恢复；危机与真实送达至少一条可视故事。对照2D与3D同版本的位置/资源/任务，降低渲染分辨率或隐藏页面后仿真结果不变。记录固定视口/机位的GPU耗时分位数、帧间隔、分辨率/LOD和错误；动态分辨率不能只报一次快照当稳定60fps。保存录像、浏览器/设备与源码SHA。

预计代价为状态适配、动态实例缓冲、交互和视觉验收；不额外引入云端GPU训练臂。它提升可观察性与沉浸，不是记忆增益实验。若E延迟，O必须独立完成既定8局与训练，最终明确3D未完成，不能用画面进度替代主线证据。

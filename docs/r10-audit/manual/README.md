# R11 手动启动包

每个 txt 文件就是一条完整消息。把文件全文粘到对应的一个新 Vibe 会话，无需粘总契约或另外给背景。共九个会话：O 集成，六条工程线 A/B/C/D/E/H，F/G 两份独立盲审。

1. 先开 [O 集成](O.txt)。随后可连续开 [A 行动](A.txt)、[B 记忆](B.txt)、[C 训练](C.txt)、[D 玩法](D.txt)、[E 浏览器](E.txt)、[H 四日对照](H.txt)。六线不用互等才开工；C 先准备训练与匿名包，H 先做 CPU 场景，GPU 由 O 排时段。
2. O 通知第一阶段盲包已就绪后，另开 [F 盲审一](F.txt)、[G 盲审二](G.txt)。用两个空白会话，分别只给对应工单及同一内容的匿名材料。两人第一阶段都封存后，O 再发第二阶段材料。
3. 共用服务器目录时，O 从各角色 STATUS.md、提交或 bundle 收件，把集成 SHA、盲包与 GPU 时段写回固定位置。各会话没有共享存储时，用分支或附带 SHA 的文件包交接。盲审材料分别投递，双方封存前不公开审阅答案。
4. 会话数有限时，优先 O/A/B/D；接着 C/H，再 E。F/G 在出包后各占一次独立会话。各线交中间产物后可在原会话续作，按实际会话数汇报。
5. 已有单项改动的会话继续用原 worktree，向 O 登记实际分支即可。总验收和预算仍见[原执行契约](../R11-EXECUTE.md)。

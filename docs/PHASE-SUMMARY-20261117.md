# FrostEcho阶段总结：从动作内核到实模四日世界

截至2026-11-17，本项目已从G00动作/事件内核推进到可玩网页、原作八张地图、持续承诺账本、真实27B候选编码与新行动头训练。当前main合入的是**阶段检查点**，不是完整原作或一般长程智能验收通过。

## 可以拿出来说明的成果

- 单一权威世界：动作提交、事件回执、资源、生存、任务/承诺、保存恢复与统一世界时钟已建立；8NPC四日、生产、议会原型、结局与轮回框架已有运行轨迹。
- 原作空间与可玩入口：50×40村庄、7室内的碰撞/路径/门与网页接通，NPC行动和交互使用同一后端；已完成真实网页单步与存档恢复验收。
- 真实JEV链路：27B冻结编码器→共享行动头→候选概率→实际权威行动；双A10运行过真实编码和训练，CPU探针/规则/回放与实模分开记账。R8新头真实履约故事9次前向；四日原图304次实模前向+40次规则晨会，8存活。
- R9继续训练4头，原始缓存/权重经独立NumPy复算；实局320次真实GPU评分与输入/候选/选择绑定成立。两臂均8存活，不能称总体策略增益。
- 独立验收：原始数据、失败轨迹、模型权重、运行环境、源码身份和SHA已有交接；R8的213份归档字节在R9独立核查中保持不变。

## 当前质量边界

R9新增延迟工作尚未完整继承既有取消、幂等、任务实例和恢复契约。已独立复现7个CPU反例：取消后仍执行、新进程恢复丢履约投影、关闭错任务、非整点分块不一致、直接执行绕过地点、未听见终态泄漏等。原“0拒绝”也漏计15次JEV/12次参考的工作结算失败。

四日runner没有承诺输入，四故事另为规则运行；因此尚未证明真实模型的跨天承诺能力。96题数据中标签、故障构造与dev饱和使小样本命中率缺少区分度；部署manifest与特征身份也需收口。正式训练准入/校准认证没有开放，不能把8NPC存活或双审满分替代这些证据。

当前审计分支修复默认测试漏发现src的盲区，补入原来只在tar中的R9测试：822项，819过、1跳过、2失败；独立strict生命周期门正确exit1。这里有意保留非零失败信号，未宣称全绿。生产修复由下一轮统一完成，避免继续按单个症状拆小轮。
